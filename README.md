# QBCore Military Job

A custom military job developed for FiveM using the QBCore framework.

Originally created in 2024, this project was built to introduce military-themed roleplay mechanics and provide a dedicated military experience within a FiveM server.

## Features

- Custom military job integration with QBCore
- Military roleplay functionality
- Configurable job settings
- Server-side and client-side Lua scripts
- Designed for FiveM roleplay servers

> Features may vary depending on the server configuration and included resources.

## Requirements

- FiveM Server
- QBCore Framework
- Lua

## Installation

1. Download or clone this repository.
2. Place the resource inside your server's resources directory.
3. Configure the resource according to your server setup.
4. Add the resource to your `server.cfg`.
5. Start your FiveM server and test the resource.

## Configuration

Customize the resource settings according to your server's requirements.
